In this folder, the content of time columns in the sheet is changed systematically.
The reference file is 'OneBookOneSheetOneTimeColumn.opju', which contains one column with ValueType='time'. The column is empty.
The other .opju files contain a varying content of the time column.
The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
