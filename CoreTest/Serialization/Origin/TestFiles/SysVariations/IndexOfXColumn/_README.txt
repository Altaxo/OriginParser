In this folder, the index of the X column changed systematically.
The reference file is 'OneBookOneSheetNineDoubleColumnsXAtA.opju', which contains nine columns. The column X is the first column 'A'.
The other .opju files contain the same number of column, but the X column is another column.

The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
