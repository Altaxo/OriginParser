In this folder, the number of sheets in a book is varied. The purpose is to find the link between sheet (@2, @3, etc.) and the sheet name, which is stored elsewhere.
The reference file is 'OneBookOneSheetTwoColumns.opju', which contains one book with one sheet.
The other .opju files contain the the same book, but with additional sheets.
The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
