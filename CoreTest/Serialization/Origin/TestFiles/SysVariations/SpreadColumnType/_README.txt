In this folder, the SpreadColumnType of columns in the sheet is changed systematically.
The reference file is 'OneBookOneSheetThreeDoubleColumns_X_Y_Y.opju', which contains three columns with SpeadColumnTypes of X, Y and Y, respectively.
The other .opju files contain the same number of columns, but with varying SpreadColumnTypes.
The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
