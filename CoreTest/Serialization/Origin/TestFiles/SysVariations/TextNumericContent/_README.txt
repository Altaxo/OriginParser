In this folder, the content of one column of ValueType: TextNumeric is changed systematically.
The reference file is 'OneBookOneSheetOneColumn.opju', which contains one column of ValueType 'double'. The column is empty.
The other .opju files populate this column with varying content.
The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
