In this folder, the DeserializedDataType of numeric columns in the sheet is changed systematically.
The reference file is 'OneBookOneSheetThreeNumericColumns_Double_Double_Double.opju', which contains three columns with ValueType Numeric and DeserializedDataType of Double, Double and Double, respectively.
The other .opju files contain the same number of columns, but with varying DeserializedDataType.
The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
