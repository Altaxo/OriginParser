In this folder, the column widths of the two columns in a sheed is varied. The purpose is to find out where the column width is coded.

The reference file is 'OneBookOneSheetTwoColumns.opju', which contains one book with one sheet and two columns.
The other .opju files contain the the same, but the column width of the two columns vary.

The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
