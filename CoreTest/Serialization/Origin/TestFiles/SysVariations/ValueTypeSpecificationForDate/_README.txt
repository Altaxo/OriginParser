In this folder, the ValueTypeSpecification of date columns in the sheet is changed systematically.
The reference file is 'OneBookOneSheetOneDateColumn.opju', which contains one column with ValueType='date' and ValueTypeSpecification='Date_DDMMYYYY_HH_MM_SS'.
The other .opju files contain a varying ValueTypeSpecification of the date column.
The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
