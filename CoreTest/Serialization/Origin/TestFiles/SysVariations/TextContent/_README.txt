In this folder, the content of text columns in the sheet is changed systematically.
The reference file is 'OneBookOneSheetTwoTextColumns.opju', which contains two columns with ValueType 'text'. The columns are empty.
The other .opju files contain the same number of columns, but with varying content.
The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
