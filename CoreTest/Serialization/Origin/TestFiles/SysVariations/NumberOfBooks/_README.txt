In this folder, the number of sheets in a book is varied. The purpose is to find the link between the columns that manifest a book and the books Longname, which is stored elsewhere. Furthermore, the project folder in which the book is stored is also of interest.

The reference file is 'OneBookOneSheetTwoColumns.opju', which contains one book with one sheet.
The other .opju files contain the the same book, plus additional books with different names and in different folders.

The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
