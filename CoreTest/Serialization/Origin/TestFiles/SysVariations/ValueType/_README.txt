In this folder, the ValueType of columns in the sheet is changed systematically.
The reference file is 'OneBookOneSheetThreeDoubleColumns_Numeric_Numeric_Numeric.opju', which contains three columns with ValueTypes of Numeric, Numeric and Numeric, respectively.
The other .opju files contain the same number of columns, but with varying ValueTypes.
The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
