In this folder, the Comment property of columns in the sheet is changed systematically.
The reference file is 'OneBookOneSheetFiveColumns.opju', which contains five columns with ValueTypes of Numeric, TextNumeric, TextNumeric, TextNumeric and Text, respectively.
The other .opju files contain the same number of columns. Only the Comment property of the column vary.
The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
