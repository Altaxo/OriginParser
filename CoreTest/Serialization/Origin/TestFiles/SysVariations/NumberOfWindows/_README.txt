In this folder, the number of windows in a book is varied. The purpose is to find where the definition of windows is stored. For this purpose, we use completely empty worksheets (with no columns at all), to make sure that the worksheet is not defined by their column content.

The reference file is 'OneEmptyWorksheet.opju', which contains one book with one sheet with no columns.
The other .opju files contain the the same worksheet, plus additional windows (worksheet, matrix).

The accompanying .txt files contain the description of the content of the respective .opju file.
The accompanying .dump files contain the dump of the content of the respective .opju file.
